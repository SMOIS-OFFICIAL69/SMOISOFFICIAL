เว็บแอปพลิเคชันระบบบริหารจัดการงานสโมสรนักศึกษา คณะสหวิทยาการ มหาวิทยาลัยขอนแก่น (วิทยาเขตหนองคาย) พัฒนาด้วย **HTML5, Vanilla JavaScript, Bootstrap 5** ทำงานร่วมกับ **Google Apps Script (Code.gs)** ในการบันทึกและซิงค์ข้อมูลลง **Google Sheets** และ **Google Drive** แบบเรียลไทม์

---

## 🌟 ฟังก์ชันการทำงานหลัก (Core Features)

### 1. 🎯 ระบบลงทะเบียนเข้าร่วมกิจกรรมนักศึกษา (Activity Registration)
* **การแสดงผลกิจกรรม**: แสดงการ์ดกิจกรรมแยกสถานะ `เปิดรับสมัคร` / `ปิดรับสมัคร` พร้อมรูปภาพ สถานที่ และกำหนดวันปิดรับ
* **การลงทะเบียนแบบคัสตอม (Dynamic Questions)**: รองรับฟอร์มลงทะเบียนที่มีคำถามพิเศษประจำกิจกรรม (เช่น ไซส์เสื้อ, การเดินทาง, Dropdown, Radio, Checkbox)
* **ยินยอมนโยบาย PDPA & ข้อมูลสุขภาพ**: รองรับการกดยืนยันยินยอมนโยบายคุ้มครองข้อมูลส่วนบุคคล และบันทึกข้อจำกัดอาหาร/โรคประจำตัว
* **ซิงค์จำนวนผู้สมัครจริง**: ซิงค์ยอดผู้ลงทะเบียนจาก Google Sheets และสรุปยอดผู้เข้าร่วมแยกสาขาวิชาและชั้นปีลงแผ่นชีทอัตโนมัติ
* **เปิดดูรายชื่อ แก้ไข และลบผู้ลงทะเบียนเรียลไทม์ (Registered Applicants Management)**: กดที่แถวกิจกรรม หรือปุ่มผู้สมัครใน Admin Dashboard เพื่อเปิดดูรายชื่อนักศึกษาที่ลงทะเบียนของกิจกรรมนั้นๆ ได้ทันที พร้อมระบบค้นหารายชื่อ แสดงข้อมูลโรคประจำตัว/คำตอบพิเศษ และสามารถ **แก้ไขข้อมูล** หรือ **ลบรายการผู้สมัคร** ออกจาก Google Sheets ได้โดยตรง

### 2. 📦 ระบบยืม-คืนอุปกรณ์สโมสรฯ (Equipment Inventory & Borrow System)
* **คลังอุปกรณ์ (Inventory Catalog)**: แสดงรายการอุปกรณ์แยกหมวดหมู่ (โต๊ะ/เก้าอี้, เครื่องเสียง, อุปกรณ์ไอที/ไฟฟ้า, อุปกรณ์สถานที่) พร้อมสถานะจำนวนคงเหลือพร้อมยืม
* **การยื่นคำร้องยืมอุปกรณ์**: นักศึกษาสามารถยื่นคำร้องระบุจำนวน วันที่ยืม-คืน โครงการ และวัตถุประสงค์
* **ตรวจสอบสถานะคำร้อง (Live Tracking)**: ค้นหาประวัติคำร้องยืมอุปกรณ์ด้วยรหัสนักศึกษา พร้อมแสดงสถานะ `รออนุมัติ`, `กำลังยืมอยู่`, `คืนเรียบร้อย`, หรือ `ไม่อนุมัติ`

### 3. 🏢 ระบบโครงสร้างองค์กรและบุคลากร (Organization & Personnel Directory)
* **ตัวกรองสังกัด/ชมรม**: กรองดูรายชื่อตามองค์กร (เช่น คณะกรรมการบริหารสโมสรฯ, อนุกรรมการสโมสรฯ, ชมรมสังกัด)
* **การ์ดสมาชิกโต้ตอบได้**: แสดงรูปโปรไฟล์ ตำแหน่ง ชื่อเล่น ช่องทางติดต่อ (Facebook, โทรศัพท์, Email)
* **หน้าต่างข้อมูลส่วนตัว (Member Modal)**: แสดงรายละเอียดสมาชิก ปุ่มกดคัดลอกช่องทางติดต่อ และปุ่มเปิดดูรูปภาพขนาดเต็ม

### 4. 📰 ระบบข่าวประชาสัมพันธ์ (News & Announcements)
* **แกลเลอรีรูปภาพหลายรูป (Multi-Image Slider)**: ข่าวสารสามารถแนบรูปภาพได้มากกว่า 1 รูป รองรับการสไลด์ Carousel และพรีวิวรูปภาพ
* **อ่านรายละเอียดข่าวสารแบบเต็ม**: แสดงสรุปข่าว เนื้อหาฉบับเต็ม ป้ายหมวดหมู่ข่าว

### 5. 📅 ระบบกำหนดการปฏิทิน (Monthly Calendar)
* **ปฏิทินนัดหมายกิจกรรม**: แสดงกำหนดการนัดหมายการประชุม งานพิธี และกิจกรรมสำคัญแยกตามรายเดือน

### 6. 🛡️ ระบบผู้ดูแลระบบ (Admin Dashboard Panel)
* **เข้าสู่ระบบผู้ดูแล**: ระบบล็อกอินสำหรับแอดมิน (`Super Admin`)
* **จัดการข้อมูลแบบ CRUD ทั้งระบบ**:
  * เพิ่ม / แก้ไข / ลบ กิจกรรม และแก้ไขฟอร์มคำถามพิเศษ
  * เพิ่ม / แก้ไข / ลบ ข่าวประชาสัมพันธ์
  * เพิ่ม / แก้ไข / ลบ กำหนดการปฏิทิน
  * เพิ่ม / แก้ไข / ลบ รายการอุปกรณ์ในคลัง
  * อนุมัติ / บันทึกการคืน / แก้ไข / ลบ คำร้องขอยืมอุปกรณ์
  * เพิ่ม / แก้ไข / ลบ องค์กร ชมรม และสมาชิกในองค์กร
  * เพิ่ม / ลบ รายชื่อสาขาวิชาในคณะ
  * เพิ่ม / ลบ บัญชีผู้ดูแลระบบ
* **สลับลำดับการแสดงผลด้วย Drag & Drop**: รองรับการลากสลับลำดับ (SortableJS) ในรายการองค์กร สมาชิก ข่าวสาร ปฏิทิน และอุปกรณ์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend**: HTML5, Vanilla JavaScript (ES6+), Bootstrap 5.3.0, Bootstrap Icons 1.11.3, SortableJS
* **Styling**: Vanilla CSS3 (Custom Design System, Glassmorphism, Responsive UI)
* **Backend**: Google Apps Script (`Code.gs`)
* **Database / Storage**: 
  * **Google Sheets**: จัดเก็บข้อมูลโครงสร้างแบบตาราง (10 แผ่นชีท)
  * **Google Drive**: สำรองไฟล์โครงสร้างระบบ (`latest_system_state.json`) และไฟล์ประวัติ
  * **LocalStorage**: แคชข้อมูลบนฝั่งเบราว์เซอร์เพื่อความรวดเร็วในการเปิดใช้งาน

## 🚀 คู่มือการติดตั้งและเปิดใช้งาน (Installation & Setup Guide)

### ขั้นตอนที่ 1: เตรียม Google Sheets
1. เปิดสเปรดชีต Google Sheets ที่ต้องการใช้เก็บข้อมูล (เช่น ลิงก์ตารางหลัก `13PkrBncnM9jSBSifhp4Q0lyvULqPxGr0kxmumHWUKdA`)
2. ไปที่เมนู **"ส่วนขยาย" (Extensions)** -> **"Apps Script"**

### ขั้นตอนที่ 2: ตั้งค่า Google Apps Script (`Code.gs`)
1. คัดลอกโค้ดทั้งหมดจากไฟล์ [`Code.gs`](file:///d:/SMOIS/student-club-web/smois-web/Code.gs) ไปวางแทนที่ในหน้าต่าง Apps Script
2. กดปุ่ม **บันทึก (Ctrl + S)**

### ขั้นตอนที่ 3: ทำให้ใช้งานเป็นเว็บแอป (Deploy Web App)
1. กดปุ่ม **"ทำให้ใช้งานได้อย่างเป็นทางการ" (Deploy)** บริเวณมุมขวาบน -> เลือก **"การทำให้ใช้งานได้อย่างเป็นทางการรายการใหม่" (New deployment)**
2. ตั้งค่าการเผยแพร่:
   * **ประเภท (Select type)**: `เว็บแอป` (Web app)
   * **ผู้เรียกใช้การทำงาน (Execute as)**: `ตัวฉัน` (Me)
   * **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน` (Anyone)  *(สำคัญมาก)*
3. กด **"ทำให้ใช้งานได้อย่างเป็นทางการ" (Deploy)** และอนุมัติสิทธิ์เข้าถึง (Authorize Access)
4. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้มา (เช่น `https://script.google.com/macros/s/.../exec`)

### ขั้นตอนที่ 4: เชื่อมต่อ URL ในไฟล์ `index.html`
เปิดไฟล์ [`index.html`](file:///d:/SMOIS/student-club-web/smois-web/index.html) แล้วแก้ไขบรรทัดที่ 2886-2887:
```javascript

const SPREADSHEET_URL = "URL_GOOGLE_SHEETS_ของคุณ";
```

## 📊 โครงสร้างตารางใน Google Sheets (Database Schema)

ระบบจะสร้างและบันทึกข้อมูลลงในแผ่นชีททั้งหมด **10 แผ่นชีท** อัตโนมัติ:

| ชื่อแผ่นชีท (Sheet Name) | รายละเอียดข้อมูลที่บันทึก |
| :--- | :--- |
| **1. สถิติระบบ** | ยอดสรุปจำนวนกิจกรรม, คำร้องยืม, อุปกรณ์, ข่าวสาร, องค์กร, ผู้ดูแลระบบ |
| **2. รายการกิจกรรม** | รายชื่อกิจกรรม, หมวดหมู่, วันจัดงาน, สถานที่, กำหนดปิดรับ, สถานะ |
| **3. รายการอุปกรณ์ในคลัง** | รายการอุปกรณ์, หมวดหมู่, จำนวนรวมในคลัง, ลิงก์รูปภาพ, รายละเอียด |
| **4. คำร้องขอยืมอุปกรณ์** | รหัสคำร้อง, วันเวลา, รหัสนักศึกษา, ชื่อ, สาขา, อุปกรณ์, วันยืม-คืน, สถานะ |
| **5. ข่าวประชาสัมพันธ์** | หัวข้อข่าวสาร, หมวดหมู่, สรุปข่าว, เนื้อหาเต็ม, ลิงก์รูปภาพ |
| **6. กำหนดการปฏิทิน** | กำหนดการนัดหมายกิจกรรมประจำวัน/เดือน |
| **7. โครงสร้างองค์กร** | รายชื่อองค์กร/ชมรม, สมาชิก, ชื่อเล่น, ตำแหน่ง, ช่องทางติดต่อ, รูปภาพ |
| **8. ผู้ดูแลระบบ** | รายชื่อบัญชีผู้ดูแลระบบ (Admin Username / Role) |
| **9. สาขาวิชา** | รายชื่อสาขาวิชาทั้งหมดในคณะ |
| **10. ข้อมูลการลงทะเบียนกิจกรรม** | รายชื่อนักศึกษาที่ลงทะเบียนเข้าร่วมกิจกรรมแต่ละงาน |
| **11. สรุปผู้เข้าร่วมกิจกรรม** | สรุปยอดผู้เข้าร่วมกิจกรรมแยกตามสาขาวิชาและชั้นปี (ปี 1 - ปี 4) |
| **12. ฐานข้อมูลนักศึกษา** | ประวัติและข้อมูลติดต่อของนักศึกษาในระบบ |
